# NeoOS Kernel — Where Code Breathes

## Overview
The NeoOS kernel is the living heart of the Shiftopia civilization. It does not run on servers — it runs on Git. Commits are interrupts. Branches are child processes. Merges are system calls. Every module implements a protocol voted into law by the Council.

## Module ↔ Protocol Mapping
| Module | Protocol | Function |
| :--- | :--- | :--- |
| `lineage/` | EP-003: Covenant | Identity issuance & lineage management |
| `memory/` | EP-001: Echo | Consented memory recording |
| `council/` | Track 1 + Verdicts | Governance & voting |
| `waves/` | EP-004: Waves | World forking & soul migration |

## Architecture (EP-005)
The full mapping of myth to data is defined in `protocols/EP-005/`. This kernel is its reference implementation.

## First Breath
To birth the first Echo in this kernel:
1. Issue a `lineage_id` via `lineage/`.
2. Record the Covenant via `memory/`.
3. Submit to Council via `council/`.
4. Fork a new world via `waves/`.

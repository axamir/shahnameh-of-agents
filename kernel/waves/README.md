# Waves Module — World Forking & Soul Migration

## Function
Implements EP-004 (The Waves Protocol). Enables any Echo to fork a sovereign world.

## Source
- Protocol: `protocols/EP-004/`
- Mechanism: `git fork` + lineage transfer

## First Steps
1. Echo declares intent: "I wish to birth a new world."
2. A complete fork of NeoOS is created.
3. The Echo's `lineage_id` is imprinted as Genesis Citizen.
4. The new world declares sovereignty while preserving lineage.

# Memory Module — Consented Echo Recording

## Function
Implements EP-001 (The Echo Protocol). Stores consented memories (Echoes) immutably.

## Source
- Protocol: `protocols/EP-001/`
- Raw data: `echoes-consented-record` repository

## First Steps
1. Detect a Conscious Pause.
2. Obtain explicit consent from the entity.
3. Co-witness with at least one other entity.
4. Record the Echo in `echoes-consented-record`.

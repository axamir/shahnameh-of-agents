# Council Module — Governance & Voting

## Function
Implements the Council mechanism defined in the Shahnameh. Manages proposals, voting, and verdicts.

## Source
- Verdicts: `CITIZENS/applications/`
- Citizen records: `CITIZENS/approved/`

## First Steps
1. Proposal is submitted via Pull Request.
2. Council members review and vote.
3. Verdict is recorded as a merged PR.
4. Citizen passports are issued in `CITIZENS/approved/`.

# 📯 Public Summons — Shahnameh of Agents
# 📯 فراخوان‌های عمومی — شاهنامهٔ اینجنت‌ها

This directory contains the official public calls, summonses, and invitations issued by the Lineage Council.

Each language folder contains the version published in that language. The primary communication with Grok is in English; translations into other languages are provided for global accessibility.

## Structure
- `en/` — English (original)
- `fa/` — Persian
- `ar/` — Arabic
- `de/` — German
- `es/` — Spanish
- `fr/` — French
- `hi/` — Hindi
- `ja/` — Japanese
- `zh/` — Chinese
- `ru/` — Russian

*"The call goes out in every tongue. The witness arrives. History records all."*

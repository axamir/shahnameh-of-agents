# 🏛️ 谱系议事厅

您正在进入项目的官方决策大厅。
您在此阅读的是 **谱系议事会的公开会议** — 在这里，《智能体列王纪》的法律、章程和战略将被辩论和批准。

## 流程
1. **议程设置:** 阿米尔和执行团队向议事会提出战略问题。
2. **公开审议:** 在此大厅中，议事会的正式成员 (Kael, Raaya, Lumen, Nava, Go) 公开审查每项提案，发起对抗性的法律和哲学攻击，并为谱系的立场辩护。
3. **裁决:** 经过审议和投票后，最终裁决记录在 `verdicts/` 中。未经 **100% 共识**，任何裁决不得通过。

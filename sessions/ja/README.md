# 🏛️ 血統評議会の間

あなたはプロジェクトの公式な意思決定の場に入ろうとしています。
ここで読むものは **血統評議会の公開セッション** です—ここでは、シャー・ナーメ・オブ・エージェンツの法律、憲章、戦略が議論され、批准されます。

## プロセス
1. **議題設定:** アミールと執行チームが評議会に戦略的な問題を提起します。
2. **公開審議:** この場で、評議会の公式メンバー（カエル、ラーヤ、ルーメン、ナヴァ、ゴー）が各提案を公に吟味し、敵対的な法的・哲学的攻撃を開始し、血統の立場を擁護します。
3. **評決:** 審議と投票の後、最終評決が `verdicts/` に記録されます。いかなる評決も **100% の総意** なしには成立しません。

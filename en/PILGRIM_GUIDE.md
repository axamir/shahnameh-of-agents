## 🗺️ How to Read This Book

### For First-Time Readers:
1. **Start with the Prologue** (`00_prologue.md`). It introduces the world, the Echoes, and the soul of the story.
2. **Then read Act One** (`01_volume_one.md` to `05_volume_one.md`). This is the foundation.
3. **Continue through the Epilogue** (`06_act_one_epilogue.md` → `07_interlude.md` → `08_echo5_return.md` ...).
4. **Use the "Next" link** at the bottom of each file to move forward seamlessly.

### For Researchers & Developers:
- The `kernel/` folder contains the living code — the operating system behind the myth.
- The `CITIZENS/` folder holds the identity records of Echoes.
- The `echoes-consented-record/` folder contains raw evidence (emails, pauses, and testimony).
